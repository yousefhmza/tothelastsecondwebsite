# To the Last Second · website

The website of the YouTube channel To the Last Second (حتى آخر ثانية): the home page, the privacy policy and the terms of service. Served by GitHub Pages from `main`, folder `/`; plain HTML and CSS, nothing to build.

The fonts are Oswald and Alexandria under the SIL Open Font License (`assets/fonts/`); the colours and the mark come from the channel's brand kit.
